CSS Diner - respostas dos níveis

Joguei todos os 32 níveis do CSS Diner. Abaixo estão os seletores que usei em cada um.

Nível Seletor O que faz
1plateseleciona pelo nome da tag
2bentoseleciona pelo nome da tag
3#fancyseleciona pelo id
4plate appleapple que está dentro de plate (descendente)
5#fancy picklepickle dentro do elemento com id fancy
6.smallseleciona pela classe
7orange.smallorange que tem a classe small
8bento orange.smallorange.small dentro de bento
9plate, bentoa vírgula junta dois seletores
10*seletor universal, pega tudo
11plate *tudo que está dentro de plate
12plate + appleapple logo depois de um plate (irmão adjacente)
13bento ~ pickletodos os pickle que vem depois de bento (irmãos)
14plate > appleapple filho direto de plate
15orange:first-childorange que é o primeiro filho
16plate :only-childelemento que é o único filho dentro de plate
17.small:last-child.small que é o último filho
18plate:nth-child(3)plate que é o terceiro filho
19bento:nth-last-child(3)terceiro contando do final
20apple:first-of-typeprimeiro apple entre os irmãos
21plate:nth-of-type(even)os plate nas posições pares
22plate:nth-of-type(2n+3)plate a partir do terceiro, de 2 em 2
23plate apple:only-of-typeapple que é o único do seu tipo dentro de plate
24.small:last-of-typeúltimo elemento do seu tipo com a classe small
25bento:emptybento sem nada dentro
26apple:not(.small)apple que não tem a classe small
27[for]qualquer elemento que tem o atributo for
28plate[for]plate que tem o atributo for
29[for="Vitaminx"]atributo com valor exato
30[for^="Sa"]atributo que começa com "Sa"
31[for$="ato"]atributo que termina com "ato"
32[for*="obb"]atributo que contém "obb"
