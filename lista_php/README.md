# lista_php

Lista de exercícios de PHP da disciplina de Programação para Internet (PPI) - IFSC Gaspar.

## Arquivos

- `index.html` - página inicial com links para os exercícios
- `1.php` - tags usadas para definir código PHP
- `2.php` - PHP roda no navegador?
- `3.php` - função hello()
- `4.php` - função randomize()
- `5.php` - sorteio de número em um intervalo
- `6.php` - par ou ímpar
- `7.php` - tabuada
- `8.php` - soma de números de uma string (explode)
- `9.php` - tamanho, palíndromo, vogais e consoantes de uma string
- `10a.php`, `10b.php`, `10c.php` - cálculo de IMC em três páginas (GET e POST)
- `11.php` - intervalo de números dentro de span
- `12.php` - classificação de triângulo
- `13.php` - soma, maior e menor de um array
- `14.php` - login simples com sessão
- `15.php` - inserir dados no MySQL
- `16.php` - listar dados do MySQL
- `conexao.php` - conexão com o banco usada nas questões 15 e 16
- `banco.sql` - script para criar o banco `lista_php` e a tabela `usuarios`
- `css/estilo.css` - estilo usado nas páginas

## Como rodar

Os arquivos `.php` precisam de um servidor PHP. Dentro da pasta, rodar:

```
php -S localhost:8000
```

e abrir `http://localhost:8000` no navegador (ou colocar a pasta no `htdocs` do XAMPP).
Para as questões 15 e 16, rodar o `banco.sql` no MySQL antes.
