# ppi1_lista_js

Lista de exercícios de JavaScript da disciplina de Programação para Internet (PPI) - IFSC Gaspar.

## Arquivos

- `index.html` - página inicial com links para os exercícios
- `1.html` - o que é JavaScript
- `2.html` - tipos de variáveis e operadores
- `3.html` - prompt e alert
- `4.html` - cálculo de IMC com if e switch
- `5.html` - sorteio de números com intervalo e contagem de repetidos
- `6.html` - números primos em um intervalo
- `7.html` - verificador de palíndromos
- `8.html` - mudança de cor de fundo com clique
- `9.html` - troca de cores com a tecla espaço
- `10.html` - calculadora
- `11.html` - eventos (click, keydown, focus, blur, mouseover, mouseout, change)
- `12.html` - localStorage
- `13.html` - canvas
- `14.html` - captura de teclas
- `imgs/` - imagens do exercício de IMC
- `css/estilo.css` - estilo usado nas páginas
