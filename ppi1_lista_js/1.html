O que é JavaScript?

Motivação

No começo da web as páginas eram estáticas: só mostravam texto e imagens. Para validar um formulário ou mudar algo na tela era preciso mandar tudo para o servidor e esperar outra página. Em 1995 a Netscape criou o JavaScript (primeiro chamado de Mocha e depois LiveScript) para deixar as páginas interativas, rodando direto no navegador. Hoje ele segue o padrão ECMAScript.

Navegador x servidor

No navegador o JavaScript roda no computador do usuário e mexe na página (DOM), responde a cliques, teclas e formulários. No servidor, com o Node.js, ele roda na máquina do servidor e pode acessar arquivos, banco de dados e rede, mas não tem página nem document.

Sandbox

No navegador o JavaScript roda dentro de uma sandbox (caixa de areia): um ambiente isolado que não deixa o script acessar os arquivos do computador nem outros programas. Isso protege o usuário de sites mal-intencionados.

Objetos globais

O navegador já oferece alguns objetos prontos: o document representa a página e permite pegar e alterar elementos; o console mostra mensagens para o programador (F12); e o alert abre uma caixinha de mensagem para o usuário.
